# Strata Planning Suite

**A free planning suite for project controls professionals, built by a planner, for planners.**

What started as a small tool to fix DCMA issues has turned into a complete planning suite. Strata is a personal project developed on my own time, shared for free with the planning community.

👉 **Website & activation key:** [www.strata.auerbach.be](https://www.strata.auerbach.be)

---

## ⬇️ Download

Download the latest version from the **[Releases page](../../releases/latest)**.

1. Download `planning_suite.exe` (or the `.zip` version if your network blocks executables)
2. Request your free activation key on [www.strata.auerbach.be](https://www.strata.auerbach.be) (sent instantly by email)
3. Launch Strata and enter your key

**Requirements:** Windows 10 / 11 · ~85 MB

## 🧰 What can Strata do?

| Module | Description |
|---|---|
| **Gantt Editor / Converter** | Edit a schedule (activities, WBS, links) and convert between Primavera P6 (XER) and Microsoft Project (MPP) |
| **Linear Schedule Viewer** | Import a Gantt and display it as a time-location (time-chainage) chart for rail, highway or pipeline |
| **AI-powered Roadmap** | Summarize schedules, critical paths and hot topics, with PowerPoint export |
| **QSRA / Risk Analysis** | Monte-Carlo schedule risk analysis with a complete risk register |
| **Time Impact Analysis** | Build collapsed as-built or impacted as-planned schedules, and compare two schedules to identify gaps |
| **DCMA Quality Check** | Full DCMA 14-point assessment, with XER comparator |
| **Reporting** | KPIs, resource-loaded S-curves and monthly report generation (Word + PowerPoint) |

---

## 🔒 Your data stays on your computer

Everything runs **locally**. Your schedules never leave your machine, unless you choose to connect an AI API (e.g. for the AI roadmap or report narrative).

The license is only used to count how many people use the tool. Nothing else is collected.

---

## ⚠️ Windows security warning

Strata is not yet code-signed, so Windows SmartScreen may show a warning on first launch. Click **More info → Run anyway**.

If your company firewall blocks the download, try from a personal computer or use the `.zip` version.
